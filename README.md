# פונקציה קווית

פרויקט ספר התרגול הגדול והמדורג בפונקציה קווית.

## מתחילים כאן

**מקור האמת היחיד והמחייב של הפרויקט:**

[`SOURCE_OF_TRUTH.md`](./SOURCE_OF_TRUTH.md)

כל GPT, AI, סוכן או מפתח שממשיך את הפרויקט חייב לקרוא את הקובץ הזה לפני כל פעולה.

## בדיקת QA מלאה

פקודת הבדיקה הרשמית של הפרויקט היא:

`powershell -ExecutionPolicy Bypass -File .\qa-all.ps1`

הבדיקה כוללת: מקור אמת יחיד, בנייה, מספור וניווט, מרחבי תשובה, רינדור כל דפי A4 ב-Chromium אמיתי, גלישות, חפיפות, חריגות רוחב, RTL, וצילומי מסך ודוח QA.

בנוסף קיים GitHub Actions workflow שמריץ QA אוטומטי על `main` וב-PR.

`meta/pages.json` הוא manifest נגזר בלבד. כרגע קיימים **12 עמודי עבודה אמיתיים**. ה־QA המלא עדיין בתהליך, ולכן עמוד 13 חסום עד שהעמודים הקיימים יעברו את בדיקות מקור האמת, A4, מרחבי התשובה והטכנולוגיה האחידה.
