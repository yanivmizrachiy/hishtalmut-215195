# פונקציה קווית

פרויקט ספר התרגול הגדול והמדורג בפונקציה קווית.

## מתחילים כאן

**מקור האמת היחיד והמחייב של הפרויקט:**

[`SOURCE_OF_TRUTH.md`](./SOURCE_OF_TRUTH.md)

כל GPT, AI, סוכן או מפתח שממשיך את הפרויקט חייב לקרוא את הקובץ הזה לפני כל פעולה.

## מצב נוכחי

- קיימים **15 עמודי ספר אמיתיים**.
- כל **15/15 העמודים בנויים ממודל נתונים משותף** ולא מ-HTML ידני חד-פעמי.
- עמודים **1–14 עברו QA חזותי ב-Chromium עם 0 שגיאות קשות**; עמוד 15 נמצא כרגע בשער ה-QA.
- עמוד 14 עוסק ב-`y=mx+b`: זיהוי `m,b`, מקדם סמוי, משמעות `b` כחיתוך עם ציר `y`, והשוואת ישרים בעלי `b` משותף.
- עמוד 15 מחבר בין `m`, `b` והגרף, כולל `b=0`, `m=0` ושחזור משוואה מתוך גרף.
- מתמטיקה נבנית באמצעות **KaTeX**; גרפים ושרטוטים מתמטיים נוצרים במנוע SVG פרמטרי משותף.
- `sources/razpages-linear/` מכיל עותק פיזי של **95/95 דפי `yanivmizrachiy/razpages`** שסווגו כפונקציה קווית, יחד עם קובצי התמיכה המקומיים הדרושים לשימורם.
- `data/razpages-linear-manifest.json` שומר את טווחי המקור, commit המקור, מספר הדפים ומספר קובצי התמיכה.
- עמוד 16 חסום עד שעמוד 15 יעבור QA מלא.

## בדיקת QA מלאה

פקודת הבדיקה הראשית היא:

`npm run qa:all`

הבדיקה כוללת:

1. מקור אמת יחיד והפניה אליו מה-README.
2. בנייה מחדש של כל 15 הדפים מתוך מודל הנתונים.
3. KaTeX מקומי ורינדור מתמטי בפועל בכל עמוד שמכיל תוכן מתמטי.
4. רצף עמודים, מספור וניווט.
5. סדר קושי, מזהי שאלות, משפחות שאלות ומרחבי תשובה.
6. תקינות טבלאות, גרפים, קני מידה, נקודות, ישרים, ישרים אנכיים ועקומות מסיחים.
7. אימות פיזי של 95/95 דפי מקור `razpages` וללא HTML זר לנושא.
8. רינדור A4 אמיתי ב-Chromium/Playwright, כולל גלישות אופקיות ואנכיות, חפיפות, RTL, מקום כתיבה וקנה מידה שווה כאשר הוא נדרש מתמטית.
9. צילומי מסך ודוח QA.

ב-Windows אפשר גם להריץ:

`powershell -ExecutionPolicy Bypass -File .\qa-all.ps1`

GitHub Actions מריץ את הבדיקה אוטומטית על `main`, על ענפי `agent/**` וב-PR ל-`main`. בענף עבודה נשמר גם `meta/visual-qa-latest.json`, כדי שתוצאת Chromium תהיה ראיה נגישה ולא סטטוס לא-מתועד.

`meta/pages.json` הוא manifest נגזר בלבד; `SOURCE_OF_TRUTH.md` הוא מקור הסמכות היחיד.
